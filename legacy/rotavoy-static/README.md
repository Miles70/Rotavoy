# Static Rotavoy retirement

Deploy this directory as the static root **only after VoyHaven is verified**. It makes no backend or provider requests. Keep the existing Railway service for VoyHaven.

The old domains remain on their working app deployment until the migration gates in `../../docs/voyhaven-migration.md` pass. This page intentionally has `noindex,follow`; public page-level 301/308 redirects can be added before the catch-all to transfer existing indexed URLs. The page's text links to VoyHaven and does not copy sensitive checkout query parameters.
